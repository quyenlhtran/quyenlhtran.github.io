# Quyen Tran’s personal website

Source for [quyenlhtran.github.io](https://quyenlhtran.github.io), built with Jekyll and the [al-folio](https://github.com/alshedivat/al-folio) starter.

## Local development

```sh
bundle install
npm ci
bundle exec jekyll serve
```

The site is available at `http://localhost:4000/`.
